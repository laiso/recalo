# Repository Guidelines

- Write all GitHub content in English, including issue and pull request titles, descriptions, review comments, and discussion comments.
- Write source-code comments and documentation in English.
- Keep the existing user-facing language as it is. The UI chrome is English and the diagnostic report flow is Japanese; do not translate one into the other as a side effect of an unrelated change.
- Update `docs/specs/` when behavior changes. Add a new decision record under `.agents/skills/recalo-decisions/references/` instead of rewriting an accepted one.
